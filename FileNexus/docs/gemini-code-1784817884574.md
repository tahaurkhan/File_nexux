# FileNexus — Technical Architecture Specification

> **Version:** 0.1.0-Draft  
> **Target Framework:** .NET 10.0 | C# 13  
> **Native Core:** Rust 2024 Edition  
> **UI Engine:** Avalonia UI (XAML / MVVM)  
> **Storage:** SQLite 3 (WAL Mode)

---

## 1. Architectural Overview

FileNexus is structured as a **hybrid multi-layer desktop application**. It separates high-level UI controls and event loops from low-level filesystem I/O and cryptographic operations.

```mermaid
graph TD
    subgraph Presentation Layer [.NET 10 / Avalonia UI]
        UI[Views / XAML Controls]
        VM[ViewModels - CommunityToolkit.Mvvm]
        NAV[Navigation Service]
    end

    subgraph Core Application Layer [.NET 10]
        DI[Microsoft.Extensions.DependencyInjection]
        SVC[Business Services / Workspaces]
        DB_CTX[SQLite ORM / Direct Queries]
        EVENT_SYS[Reactive FileWatcher Coordinator]
    end

    subgraph Native Engine Layer [Rust filenexus_engine]
        FFI[C-FFI Interop Bridge]
        SCANNER[Parallel Directory Crawler]
        HASHER[SIMD SHA-256 Hashing Engine]
        PARSER[Format Metadata Extractors]
    end

    subgraph Storage & OS Layer
        SQLITE[(SQLite Local Database)]
        OS_FS[OS File System - Windows / Linux]
    end

    UI <-->|Data Binding & Commands| VM
    VM <-->|Async Invocations| SVC
    SVC <-->|Transactions| DB_CTX
    DB_CTX <-->|Reads/Writes| SQLITE
    SVC <-->|P/Invoke / Unmanaged Calls| FFI
    FFI <-->|Native Traversal| SCANNER
    SCANNER -->|Low-level I/O| OS_FS
    EVENT_SYS <-->|OS File Events| OS_FS
